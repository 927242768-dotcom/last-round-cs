# 作品管理

当前公开网站的后台为 <https://927242768-dotcom.github.io/admin/>。它直接更新 Pages 发布仓库，不会修改源码仓库。自行部署的 Node 版本通过自己站点的 `/admin` 管理内容。

## Pages 后台登录

1. 按登录页说明创建细粒度 GitHub 访问令牌。
2. Repository access 选择 **Only select repositories**，仅授权 `927242768-dotcom.github.io`。
3. 将仓库的 **Contents** 权限设为 **Read and write**，复制令牌并登录后台。

令牌只保存在当前页面内存，不写入仓库或浏览器存储。刷新、关闭页面或退出后需要重新登录；令牌过期后需要重新创建。令牌所属账户必须有发布仓库写入权限。

保存作品会更新发布仓库 `main` 分支中的两个文件：

- `data/works.json`：包含全部作品，供后台编辑。
- `api/works`：仅包含已发布作品，供前台读取。

上传素材存入 `media/uploads/`。保存或上传会产生 Git 提交，网站需等待 GitHub Pages 发布完成后更新。

## 新增与编辑

填写标题、分类和视频地址，按需要补充简介、封面、排序与发布状态。图片和视频可上传，也可填写 HTTP、HTTPS 或站内地址；视频应使用可直接播放的媒体链接。

| 字段 | 限制 |
| --- | --- |
| 标题 | 必填，最多 120 字 |
| 分类 | 必填，最多 60 字 |
| 简介 | 最多 3000 字 |
| 封面与视频地址 | 每项最多 2048 字；视频必填，封面可空 |
| 排序 | `0` 到 `999999` 的整数，数字较小的作品优先展示 |
| 发布状态 | 关闭时不进入前台作品列表 |

上传支持 JPG、PNG、GIF、WebP、AVIF、MP4 和 WebM。Pages 单文件上限为 **25 MiB**；更大的视频可以使用外部视频直链。上传后还需保存作品，才能把素材地址关联到作品记录。

Pages 发布仓库是公开仓库。草稿虽不进入前台列表，记录仍保存在公开的 `data/works.json` 中，上传素材也可通过文件地址访问，草稿不是私密存储。

## Node 版本

Node 后台使用部署时设置的 `ADMIN_PASSWORD` 登录，HMAC 签名会话有效期为 8 小时。更换管理密码或会话密钥后，原会话失效。

作品保存到数据目录中的 `last-round.sqlite`，素材保存到 `uploads/`，单文件上传上限为 **90 MiB**。正式容器部署应将数据目录设为 `/data` 并挂载永久数据卷。它与 Pages 仓库的数据独立，切换部署方式不会自动迁移内容。

## 删除与日常维护

删除作品会删除其记录，不会自动删除已经上传的媒体文件。清理素材前应先备份，并确认文件没有被其他作品或页面引用。

遇到 Pages 仓库已被另一处更新的提示时，先确认最近保存的内容，再刷新后台重新编辑。维护源码并重新发布网站前，必须先同步发布仓库，保留后台保存的作品与上传素材，具体步骤见[部署说明](deployment.md)。
