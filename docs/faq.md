# 常见问题

[文档首页](README.md)

## 应该在哪个仓库修改？

网页代码、构建工具和文档在 `last-round-cs` 维护。`927242768-dotcom.github.io` 是线上发布仓库，后台会向它保存作品。两个仓库的分工见[项目首页](../README.md)。

## 保存后为什么主页没有立即更新？

GitHub Pages 需要完成重新发布，浏览器或 CDN 也可能暂时保留旧内容。先查看发布仓库的 Actions / Pages 状态，待构建完成再刷新；不要反复点击保存。

## 后台应该输入什么密码？

线上 Pages 后台输入本站专用的 GitHub 细粒度访问令牌，仅选择发布仓库，并给予 Contents 读写权限。页面有创建说明。Node 独立服务才使用 `ADMIN_PASSWORD`。

## 刷新后台后为什么要重新登录？

Pages 后台令牌仅保留在当前页面内存，刷新或退出后清除，不写入仓库或浏览器持久存储。

## 草稿和未上架素材是私密的吗？

不是。草稿只是不出现在前台列表；公开发布仓库中的作品数据和文件仍可被访问。

## 视频上传有什么限制？

Pages 单文件最大 25 MiB，Node 最大 90 MiB。支持 MP4、WebM；也可填写可公开访问的视频直链。外部平台的观看页面通常不能直接作为视频文件地址。

## Node 服务为什么启动失败？

确认 Node 为 24.x、管理密码已设置、会话密钥不少于 32 字符。`npm start` 使用已有环境变量；本地 `.env` 请使用 `npm run dev` 或 `npm run start:local`。

## 如何避免发布覆盖新增的作品？

发布前同步发布仓库，保留 `data/works.json`、`api/works` 和 `media/uploads/`。构建脚本会读取已有作品数据，但不能把空目录或读取失败后的种子数据当作线上作品覆盖回去。流程见[部署与备份](deployment.md)。
